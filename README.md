# Task 4 – Dashboard Design

## Objective

The objective of this task was to design an interactive
sales and financial dashboard for business stakeholders
using Tableau.

## Tool Used

- Tableau

## Dataset

Superstore Dataset

## KPIs

- Total Sales
- Total Profit
- Profit Margin
- Sales Growth

## Dashboard Features

- Interactive Region filter
- Category filter
- Year filter
- Sales trend analysis
- Sales by category
- Sales by region
- Profit by region
- Profit by category
- Top 10 products
- KPI cards
- Dashboard navigation
- Consistent color theme

## Business Insights

- Sales performance was analyzed over time.
- Category-wise sales performance was compared.
- Regional sales and profitability were analyzed.
- Top-performing products were identified.
- Profitability was compared across categories and regions.
- Interactive filters allow stakeholders to explore
  different segments of the data.

## Files Included

- Tableau dashboard workbook
- Dataset
- Dashboard screenshots
- PPT summary

## Conclusion

The Tableau dashboard provides an interactive way to
analyze sales, profit and growth and helps business
stakeholders make data-driven decisions.
